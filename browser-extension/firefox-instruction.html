🧩 Установка PP Jira Bridge

Расширение для интеграции Planning Poker с Jira

🦊 Mozilla Firefox
📌 Важно для Firefox

Firefox требует подписи расширений. Для разработки используйте временную установку. Для постоянного использования расширение нужно подписать через Mozilla Add-ons.

⚡ Временная установка
🔒 Постоянная

Шаг 1: Скачайте расширение

📦 Скачать ZIP-архив

Шаг 2: Временная загрузка

1

Откройте страницу отладки

Вставьте в адресную строку: about:debugging#/runtime/this-firefox

2

Нажмите "Временная загрузка дополнения..."

Кнопка находится в центре страницы

3

Выберите файл manifest

Распакуйте ZIP и выберите файл manifest-firefox.json

4

Обновите Planning Poker

Вернитесь на страницу и обновите её (F5)

ℹ️ Примечание: Временное расширение работает до перезапуска Firefox. После перезапуска нужно загрузить его заново.
← Вернуться на Planning Poker
🔐 Требуется подпись

Для постоянной установки расширение должно быть подписано Mozilla. Есть два пути:

Вариант 1: Официальная публикация

1

Зарегистрируйтесь на Mozilla Add-ons

addons.mozilla.org/developers/

2

Загрузите расширение

Нажмите "Submit a New Add-on" и загрузите ZIP-архив

3

Дождитесь проверки

Обычно занимает 1-3 дня. После одобрения расширение можно установить из магазина

Вариант 2: Внутреннее использование

Для Firefox Developer Edition / Nightly:
1. Откройте about:config
2. Найдите xpinstall.signatures.required
3. Установите значение false
4. Перезапустите Firefox
5. Установите расширение через about:addons
📦 Скачать для подписи
📸 Иконка расширения появится в панели инструментов Firefox
(возле адресной строки)
