# Инструкция по установке PP Jira Bridge

## 📋 Быстрая установка

### Для Chrome / Edge / Chromium

1. **Скачайте** архив `pp-jira-bridge-chrome.zip`
2. **Распакуйте** архив в любую папку
3. Откройте `chrome://extensions/` (или `edge://extensions/`)
4. Включите **Режим разработчика** (Developer mode)
5. Нажмите **Загрузить распакованное расширение** (Load unpacked)
6. Выберите папку `build-chrome/` из распакованного архива
7. ✅ Готово! Иконка расширения появилась в панели

### Для Firefox (разработка / тестирование)

1. **Скачайте** архив `pp-jira-bridge-firefox.zip`
2. Распакуйте его в любую папку
3. Откройте `about:debugging#/runtime/this-firefox`
4. Нажмите **Временная загрузка дополнения...** (Load Temporary Add-on)
5. Выберите файл `manifest-firefox.json` из папки `build-firefox/`
6. ✅ Готово! Расширение работает до перезапуска браузера

> ⚠️ **Важно:** Временное расширение исчезает после перезапуска Firefox. Для постоянной установки нужна подпись от Mozilla.

### Для Firefox (постоянная установка)

Есть 3 варианта:

#### Вариант 1: Официальная публикация (рекомендуется)

1. Зарегистрируйтесь на [Firefox Add-ons Developer Hub](https://addons.mozilla.org/developers/)
2. Нажмите **Submit a New Add-on**
3. Загрузите `pp-jira-bridge-firefox.zip`
4. Дождитесь проверки (обычно 1-3 дня)
5. После одобрения установите расширение из магазина

#### Вариант 2: Self-distribution (для внутреннего использования)

1. Откройте `about:config`
2. Найдите `xpinstall.signatures.required`
3. Измените значение на `false`
4. Перезапустите Firefox
5. Откройте `about:debugging` и загрузите расширение как временное
6. Теперь оно будет сохраняться после перезапуска

> ⚠️ Этот метод работает только в **Firefox Developer Edition** или **Nightly**

#### Вариант 3: Подписать самостоятельно (сложно)

Можно создать собственный сертификат, но это требует дополнительных настроек.

## 🔧 Настройка расширения

После установки:

1. Кликните на иконку расширения 🔗 в панели браузера
2. Введите **URL вашей Jira**:
   - Для Atlassian Cloud: `https://your-company.atlassian.net`
   - Для самописной Jira: `https://jira.your-company.com`
3. Получите **API Token**:
   - Перейдите на [id.atlassian.com/manage/api-tokens](https://id.atlassian.com/manage/api-tokens)
   - Нажмите **Create token**
   - Дайте имя (например, "PP Jira Bridge")
   - Скопируйте токен (виден только один раз!)
4. Вставьте токен в поле **API Token**
5. Нажмите **Проверить подключение**
   - ✅ Если всё работает, увидите имя пользователя
6. Нажмите **Загрузить список полей**
7. Найдите поле для Story Points (обычно `customfield_XXXXX`)
8. Введите ID поля в **ID поля Story Points**
9. (Опционально) Укажите ID поля Epic Link
10. Нажмите **Сохранить настройки**

## 🐛 Решение проблем

### "Не удалось подключиться к Jira"

1. Проверьте URL Jira (без слэша в конце)
2. Убедитесь, что Token действителен
3. Проверьте, что у токена есть права на доступ к API
4. Откройте консоль разработчика (`F12`) и посмотрите ошибки

### Firefox: "Extension is not signed"

- Используйте временную загрузку через `about:debugging`
- Или подпишите расширение через Mozilla Add-ons
- Для внутреннего использования: `about:config` → `xpinstall.signatures.required = false`

### "Поля не загружаются"

- Убедитесь, что у вашего токена есть права на просмотр полей
- Проверьте, что Jira доступна из браузера
- Попробуйте обновить страницу настроек

### Настройки не сохраняются

- Очистите кэш расширения (кнопка "Очистить настройки")
- Перезагрузите браузер
- Проверьте, что расширение не отключено

## 📞 Поддержка

Если возникли проблемы:

1. Проверьте консоль разработчика (`F12` → Console)
2. Сделайте скриншот ошибки
3. Создайте issue в репозитории

## 🔄 Обновление

### Chrome

1. Удалите старое расширение
2. Загрузите заново через `chrome://extensions/`

### Firefox (временное)

Просто перезагрузите через `about:debugging`

### Firefox (подписанное)

Обновление автоматически подтянется из магазина
