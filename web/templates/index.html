📦 СКАЧАТЬ РАСШИРЕНИЕ
🌐 Google Chrome / Edge / Chromium:
  1. Распакуйте скачанный ZIP-архив
  2. Откройте chrome://extensions (или edge://extensions)
  3. Включите Режим разработчика (в правом верхнем углу)
  4. Нажмите Загрузить распакованное расширение
  5. Выберите папку build-chrome из архива
  6. Обновите страницу Planning Poker (F5)
🦊 Mozilla Firefox:
  1. Распакуйте скачанный ZIP-архив
  2. Откройте about:debugging#/runtime/this-firefox
  3. Нажмите Временная загрузка дополнения...
  4. Выберите файл manifest-firefox.json из папки build-firefox
  5. Обновите страницу Planning Poker (F5)
⚠️ Временное расширение работает до перезапуска Firefox. Для постоянной установки нужно подписать расширение через Mozilla Add-ons.
📖 Как установить:
  1. Распакуйте ZIP в отдельную папку
  2. Откройте страницу расширений вашего браузера
  3. Включите режим разработчика
  4. Загрузите распакованное расширение
  5. Укажите папку build-chrome (для Chromium) или build-firefox (для Firefox)
